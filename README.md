# 🧮 Matemáticas en el Mundo Real: Fibonacci y Números Primos

¡Bienvenido a mi proyecto del Desafío Web! Esta es una aplicación práctica e interactiva que demuestra cómo dos conceptos matemáticos que vemos en clase (la **Sucesión de Fibonacci** y los **Números Primos**) sirven para resolver problemas reales del día a día, como las finanzas y la seguridad digital.

---

## 💡 ¿Qué problemas de la vida real resuelve esta página?

Para que el proyecto sea útil y entretenido, la aplicación se divide en 3 herramientas prácticas que puedes probar desde el menú de pestañas:

1. **💰 Plan de Ahorro Inteligente (Usa Fibonacci):** * **El problema:** A veces es difícil ahorrar una cantidad fija al mes, o queremos un reto que crezca con el tiempo.
   * **La solución:** Esta herramienta calcula un plan donde cada mes guardas la suma de los dos meses anteriores ($Bs. 0, 1, 1, 2, 3, 5, 8...$). Es un método excelente para aumentar tu disciplina de ahorro de forma progresiva.

2. **🔒 Validador de Claves de Seguridad (Usa Números Primos):** * **El problema:** Los hackers usan computadoras para adivinar contraseñas numéricas fácilmente si son números muy comunes.
   * **La solución:** En la vida real, los bancos usan números primos muy grandes porque son casi imposibles de hackear o descomponer. Esta herramienta analiza si el código que ingresas es primo (seguro) o si es vulnerable.

3. **⚙️ Generador de Claves Avanzadas (Mezcla de Ambos):** * **El problema:** Las secuencias de números que crecen siempre igual son fáciles de predecir por un virus.
   * **La solución:** Esta herramienta genera la serie de Fibonacci y, al mismo tiempo, detecta y resalta en verde cuáles de esos números son primos. Esta combinación se usa en la vida real para crear sistemas informáticos de alta seguridad.

---

## 🛠️ ¿Cómo está construido el proyecto?

El proyecto utiliza únicamente las tres tecnologías web fundamentales (sin usar librerías raras ni marcos externos):

* **HTML5:** Para armar la estructura de la página, los textos explicativos y los formularios donde escribes los números.
* **CSS3:** Para que la página se vea moderna, limpia y, lo más importante, **responsiva** (se adapta perfectamente si la abres desde un celular o desde una computadora).
* **JavaScript:** Es el "cerebro" que hace los cálculos matemáticos al instante y cambia lo que ves en pantalla cuando presionas los botones.
